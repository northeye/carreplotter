# carreplotter.northeye.org

Website of the CarReplotter app (GitHub Pages): the top page, support contact and privacy policy, in English and Japanese.

| Page | English | Japanese |
| --- | --- | --- |
| Top / support | `index.html` | `ja/index.html` |
| Privacy policy | `privacy.html` | `ja/privacy.html` |

Plain HTML and CSS without a build step (`.nojekyll`). `CNAME` sets the custom domain.
When you change the privacy policy, update "Last updated" in both languages.
